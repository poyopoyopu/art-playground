# fireworks-21 の効果音(本物の花火の録音)

> **現在は使っていない**(2026-11-09: おっちゃんが「音は無しでいい」と判断し、fireworks-21.html から音の機能を外した)。AGENTS.mdの「ファイルを消さない」ルールにより、素材だけ残してある。音を戻すときは、`git log` の 5f115ed〜ab5db3e あたりの fireworks-21.html に音のコードがある。

`prototypes/fireworks-21.html` が使う、実際の花火を録音した効果音。

- 元: rubberduck「25 CC0 bang / firework SFX」(OpenGameArt、https://opengameart.org/content/25-cc0-bang-firework-sfx)
- ライセンス: **CC0 1.0**(著作権放棄。クレジット不要・商用可)
- 入手経路: GitHub `lavenderdotpet/CC0-Public-Domain-Sounds` の `25-CC0-bang-sfx`(同じ内容、CC0)
- 加工: 頭の無音を削る/音量をそろえる/mp3(モノラル96kbps)に変換(iPhoneのSafariがoggを読めないため)
- ファイル: `bang*.mp3` `cannon*.mp3` `fw01/06.mp3`=炸裂(低い=大玉・高い=小玉で使い分け)、`fw02/03.mp3`=パチパチ(はぜる玉)、`fwloop.mp3`=きらめきのパチパチ
